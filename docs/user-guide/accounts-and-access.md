# Accounts, approval and recovery

Create a user-ID account, understand approval, maintain access and recover a password without relying on email.

## Create an account without email
1. Open [Create your PV Info account](https://www.pvinfo.org/request-access.html).
2. Choose a unique user ID rather than your legal name. Follow the format validation shown by the form.
3. Choose and confirm your own password. Use the form's password requirements; the current password setup expects a strong password of at least 12 characters. Use Show password only in a private setting.
4. Optionally select a professional role. It personalizes context; it does not authorize editing or administration.
5. Select Create my account and read the resulting approval information.
6. Save the recovery key securely when it is offered. Treat it like a password and keep it outside the app in an appropriate password manager.

You do not need to submit a name, date of birth, phone number or public contact address for this flow. Do not create a second account to fix a password problem with an existing one.

## Sign in and check approval
Open [Account and team](https://www.pvinfo.org/account.html), enter your user ID and password, and select Sign in securely. A pending user can browse public content and open [Approval status & messages](https://www.pvinfo.org/account-status.html). This page checks status and administrator messages while it remains visible; Check for updates requests another check.

Approval unlocks the personal company workspace and other authorized saves. If approval is recorded but the app still shows pending access, sign out and sign in once to refresh the session. If access was declined, read the administrator's explanation; Request reconsideration is available when applicable. Approval is not communicated by a guaranteed email notification.

## Account preferences and passwords
In Account and team, use Save account preferences for supported user-ID/professional-role preferences. Set or change password requires entering and confirming a new password. Signing out ends the current app session; it does not erase browser-only data or revoke copies of exported files. The header intentionally does not display your name or email.

An administrator-provisioned account follows a different first-sign-in path: enter the supplied temporary credentials, choose a permanent password when prompted, then sign in with it. Temporary credentials expire and are not a shared default password.

## Recover a forgotten password
1. Open Account and team and expand Forgot password? Use your recovery key.
2. Enter your user ID, the recovery key and a new permanent password.
3. Select Reset password using a key and follow the confirmation before signing in again.
4. An older, unused recovery code may also be accepted for an existing account. Do not assume every historical code remains valid.

Generate or replace recovery key invalidates earlier keys/codes. Copy the new secret when shown; it is not a message to the administrator. The UI clears displayed secrets when appropriate, so do not depend on retrieving them later.

## If you lost both password and key
Use Request administrator assistance on the account page. This records a support request; it does not prove ownership, reveal a password or automatically issue a reset. An administrator must handle identity verification through an appropriate process. A public user-ID request by itself must not transfer an account to someone else.

## Existing email sign-in
Sign in by email instead remains available for existing email-backed accounts when configured. Request one link, use the newest message and wait if a rate limit appears. Repeated requests can worsen the limit. New user-ID accounts do not need this email path. The approval-status messages and password/key flow do not depend on email delivery.

## Teams
Approved users can create or join a team through Account and team. Use only an invitation from the intended team owner and confirm the selected team before saving work. Team membership determines who can see that team's work. See [My PV Briefing and teams](personal-briefing.md) and [Action Center](action-center.md) for the difference between personal and team records.
