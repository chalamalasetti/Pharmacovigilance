# Safety resources and reference tools

Use the public safety-database directory and distinguish a useful reference link from an ingested data source.

## Browse the resource directory
Open [Public Safety Data Resources](https://www.pvinfo.org/resources.html). Search and combine the available category, specialty, jurisdiction/product and access filters. Read What this directory covers and Which resource should I use? before comparing resources.

Open a resource to inspect its organization, purpose, coverage, access/reuse conditions, limitations, official URL and verification/link status. Follow the original database's documentation for its permitted uses and interpretation limits. A publicly available reporting database can have duplicates, missingness and reporting bias; its presence in this directory is not a claim that it measures incidence or establishes causality.

## Resource directory versus collection
| Item | What it means |
| --- | --- |
| Resource listing | A reference to a public database/tool/organization. It can be useful without its records being downloaded into PV Info. |
| Collected indicator | The listing is associated with a configured collection source according to the app's current evidence. It does not imply complete ingestion of that database. |
| Data source | A configured feed/API/page/news search used by the collection pipeline. Administrators manage this separately. |
| Source document | A specific regulatory document family with captured versions and provenance. It has its own monitoring/extraction workflow. |

Do not assume that listing every public safety database means the app imports individual case data. PV Info's workflow should use appropriate public organizational/regulatory evidence without inviting patient-level submissions.

## Suggest or report a resource
Use Suggest a resource for a relevant public organizational reference, or the supported feedback/broken-link controls where available. Provide the official resource name, URL and a concise organizational reason. Do not enter patient cases, personal identifiers, private credentials or confidential company material. Submitting a suggestion does not guarantee publication or collection.

## Administrator actions
Open [Safety data resources administration](https://www.pvinfo.org/admin-resources.html). Search records, add/edit permitted metadata, set publication status, review linked collection status and record link-verification evidence. Resource activation/publication is separate from enabling a feed in Data sources. Review feedback and record its disposition using the available controls.

Saved directory changes can await the next public data publication. Verify the public resource page after publishing; do not assume a database save means every visitor already sees the new snapshot.
