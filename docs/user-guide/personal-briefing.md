# My PV Briefing, workspace and teams

Tailor your reading view, maintain saved work, and distinguish local, personal and shared records.

## Build a reading profile
1. Open [My PV Briefing](https://www.pvinfo.org/briefing.html).
2. Use the introductory profile flow or Edit profile to select the view you read for, countries, topics and watchlist terms.
3. Select Show my briefing or Save profile. Skip and show everything is useful when you are exploring before choosing a scope.
4. Choose Last 24 hours, Since my last visit, Last 7 days or Last 30 days.
5. Review New on what you follow, More in your scope, Coming up and My work. These are different presentations of available evidence and workspace records, not separate source collections.

The reading profile is distinct from a confirmed company portfolio. Selecting a safety-systems role or a watchlist term does not select the company's products and markets for an assessment.

## Organize groups
Groups lets you rename or add reading views. Use Add a group, edit the supported labels/preferences, then Save groups. Cancel discards unsaved group edits. Group names are personal organization aids; they do not create access-control roles, operating procedures or regulatory approvals.

## Save and review work
Open an impact card, save it, or record the supported assessment/dismissal action with a reason. My work brings saved and pending items back into view. Changes to source content do not by themselves close your work. For assigned actions and verified closure, use the separate Action Center case workflow.

## Understand where data is stored
| Scope | Storage and sharing behavior |
| --- | --- |
| This browser only | Local browser storage. It can be lost if site data is cleared, a different browser is used or storage is unavailable. It is not a cross-device or independently verified team record. |
| Approved personal account | Supported account/workspace records are saved under the signed-in account. Other ordinary users cannot browse your personal company work merely by selecting the same public company. |
| Selected team | Team-authorized records are visible to the team's members. A company name alone does not define team access. |

Signing in does not mean every type of local object has automatically become a team record. Check the active scope on each workflow. Explicitly select the intended team rather than assuming the last-used team is correct.

## Create and join teams
Use [Account and team](https://www.pvinfo.org/account.html) to create a team or join with an invitation. Follow the displayed team controls for available invitation and membership operations. Protect invitation codes and share them only with intended participants. A member's professional-role text is not proof of regulated-role qualification.

[Team queue](https://www.pvinfo.org/team.html) shows the shared update assessments/assignments and activity available to the selected team. It is related to, but not interchangeable with, the company Action Center. Use the Action Center when you need the full company applicability, owner, evidence and closure record.

## Export and import
Export workspace (JSON) creates a portable snapshot of supported briefing/workspace data. Import workspace loads a compatible exported snapshot; read any confirmation and check the resulting profile/items. Export assessments (CSV) provides the supported assessment view for analysis.

These exports are not guaranteed to include every cloud case, team membership, source original or database audit event. Use Export this private case for an Action Center case package. Keep downloads in an approved location and inspect them before sharing; they may include organizational work and authorized email identifiers.

## Verify a save
Look for the success message, reload the relevant screen and confirm the item appears in the intended scope. If a conflict or sync error is shown, keep your unsaved text and resolve it before assuming a cloud save succeeded. Browser-only evidence is useful for exploration but should not be represented as an independently approved regulated record.
