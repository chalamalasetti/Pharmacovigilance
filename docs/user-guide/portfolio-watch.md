# Portfolio Label Watch

## Import and review

Open portfolio-watch.html. Upload a CSV containing business product information only, with a market column (US, EU or CA) and a brand, ingredient or identifier. Use the downloadable header template. Maximum size is 200 KB and 500 product rows. The file remains in this tab; the app requests source datasets without uploading your CSV.

Confirm one source record or exclude each row. Supplied fields constrain candidates; nothing is automatically confirmed. If more than 100 records match, narrow the input before confirming. Source company roles do not establish ownership. Availability depends on source coverage and a secure browser context for verified repository retrieval.

## Create a private package

Create reviewed portfolio to inspect ingredients, source company roles, source dates and available US journey links. Download the private JSON package to retain selections and provenance. Closing or reloading the tab discards the in-memory work. This preview has no package restore, account sync, scheduled monitoring or alerts. A new import replaces the current in-memory preview.

The package includes portfolio selections and should remain private. No reporting deadline, complete label history or first approved safety-term addition is inferred from the matched source record.
