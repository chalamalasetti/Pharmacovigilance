# Portfolio Label Watch

## Import and review

Open **Label Intelligence → Portfolio Label Watch**. Upload a CSV containing business product information only, with a market column (US, EU or CA) and a brand, ingredient or identifier. Use the downloadable header template. Maximum size is 200 KB and 500 product rows. The file remains in this tab; the app requests source datasets without uploading your CSV.

Confirm one source record or exclude each row. Supplied fields constrain candidates; nothing is automatically confirmed. If more than 100 records match, narrow the input before confirming. Source company roles do not establish ownership. Availability depends on source coverage and a secure browser context for verified repository retrieval.

## Create a private package

Create reviewed portfolio to inspect ingredients, source company roles, source dates and available US journey links. Download the private JSON package to retain selections and provenance. Closing or reloading the tab discards the in-memory work. Restore a downloaded JSON package to load its product identities as an unverified baseline. Current source metadata is compared against saved hash, status and approval-date values. All matches require confirmation again. Missing records do not establish withdrawal, and metadata differences do not establish label wording changes. This preview has no account sync, scheduled monitoring or alerts. A new import replaces the current in-memory preview.

The package includes portfolio selections and should remain private. No reporting deadline, complete label history or first approved safety-term addition is inferred from the matched source record.
