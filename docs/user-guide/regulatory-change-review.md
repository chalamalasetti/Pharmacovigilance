# Regulatory Change Review

Compare source captures, record human triage and open a company assessment with pinned evidence.

## Find a source change
Open [Regulatory Change Review](https://www.pvinfo.org/changes.html). Search source reviews, filter agency/jurisdiction/triage status and use Reload register after new captures. Select a change to open its three workflow tabs. An initial capture may have no prior version; missing predecessor evidence must not be interpreted as proof that every clause is new.

## 1 · Compare evidence
Review Previous capture and Current capture, their source links and version details. Use Show changed sections only to focus on extracted additions/deletions/modifications, then turn it off to inspect context. Show next 40 comparison sections loads more text where available.

Read warnings for partial extraction, changed structure, unsupported/scanned content, missing dates or other uncertainty. Open both original documents where available. A parser change, page relocation or formatting change can produce a text difference without a legal amendment. If comparison is incomplete, record that and perform the necessary manual review rather than declaring no impact.

## 2 · Human triage
An authorized administrator/editor records the source-level interpretation. The current implemented access check is administrator-based; do not infer a separate regulatory-reviewer permission simply from a professional-role label.

1. Select Change type.
2. Enter Reviewer summary describing the source change, not a company implementation conclusion.
3. Select the Triage decision: a reviewed handoff, more information needed or informational disposition as appropriate to the available choices.
4. Enter Rationale, scope and uncertainty.
5. Confirm manual comparison only if you compared the original documents, including relocated text and exceptions.
6. Select affected approved requirement versions when supported. No selection records an unmapped baseline; it is not proof that no requirements are affected.
7. Select Save triage decision and inspect the new review revision.

Saving triage does not publish a baseline change automatically. If a new interpretation is needed, use the baseline/library review workflow separately.

## 3 · Company assessment
After appropriate human triage, use Company assessment:
1. Choose a confirmed company portfolio.
2. Choose My private account or an authorized team privacy scope.
3. Recheck product/market freshness. Explicitly confirm outside-market monitoring only when intended.
4. Select Open private assessment.
5. Select Continue in Action Center and decide company applicability there.

The case pins source captures, comparison/triage review and affected requirement evidence. A newer triage review may govern new handoffs while an existing assessment retains the earlier review it actually used. Inspect that pinned context when reopening older work.

## Separation of decisions
A source difference answers what text may have changed. Human triage classifies that evidence. The approved baseline records a reviewed interpretation. Company applicability decides whether and how it affects the selected business. Assigned work and verified closure come later. Completing one step does not imply the next has been approved.
