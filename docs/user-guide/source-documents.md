# Source Documents and provenance

Find official source documents, inspect captured versions and reach extraction and baseline review.

## Find a document
Open [Source Documents](https://www.pvinfo.org/documents.html). Combine Search documents, country/jurisdiction, agency, topic, lifecycle and document type. Use Published from/through for stated source publication dates and Monitoring for active/inactive collection configuration.

Select a result to inspect the source title, issuing agency, classification, source dates and latest capture evidence. Official primary source identifies the provenance category. It does not prove that the parser captured every clause or that the source's legal force was correctly interpreted.

## Inspect captured versions
1. Use Captured document version to choose a version rather than assuming the latest is the one relevant to your case.
2. Open agency source for the regulator's current publication.
3. Use Download archived original where available to inspect the captured original. Its bytes may differ from the current official URL after a revision.
4. Read Evidence checksum & method, retrieval/capture details and capture status.
5. Use View linked baseline requirements to find interpretations derived from that source family.

The original hash identifies captured bytes; the content hash/parser information describes extraction. Reprocessing unchanged bytes with an improved parser is not proof of a regulatory amendment. Source publication date, effective date and retrieval date are separate facts.

## Understand capture and extraction states
Not captured means the record is registered but no usable capture is present. Metadata-only means you have a reference record without extracted document text. Partial/unsupported extraction requires manual review. An unchanged byte comparison can preserve a prior capture or reprocess extraction without inventing a new legal change.

Extraction candidate view filters candidates such as Awaiting review, Potential changes, Unchanged text and Accepted into baseline library. Open a candidate to inspect its source anchor, quoted text, context, prior match and comparison. Link to this exact candidate is a provenance link, not an approval.

## Review automatic drafts
Review automatic baseline drafts opens the admin-only [Baseline Review](baseline-review.md) desk for the captured document. Automatic preparation reduces retyping; it does not certify completeness. A source can contain tables, cross-references, exceptions, scanned content and non-normative material that need human examination.

The older Match & draft baseline candidate route also exists for explicit matching to a stable requirement. Use it deliberately when a candidate must be linked to an existing obligation; do not create a parallel stable ID for the same meaning. Reject candidate and Need more information record a rationale. Such organizational editorial notes are public-facing record content, so exclude confidential company decisions and personal details.

## Administrator: register or edit a source
1. Select Register an official document, or Edit monitored source for an existing record.
2. Choose a verified agency and matching jurisdiction. Use the official source URL and a stable source-family ID.
3. Complete title/edition, topic, lifecycle, authority metadata, legal basis/applicability context, dates when known and capture frequency/monitoring status.
4. Leave unknown dates unknown; do not substitute retrieval time as publication/effective date.
5. Select Save document source. Automatic collection/extraction is scheduled; Capture now requests an immediate supported capture when available.
6. Revisit the captured version and Baseline Review. Saving a source does not publish its extracted drafts.

Only approved agency domains and supported official URLs can be captured. An access-denied landing page, unsupported PDF or scanned source may need editorial intervention rather than repeated capture requests.

## Agency directory and coverage gaps
Global agency directory & coverage gaps shows supported agency records and verification state. Administrators can register/edit an agency, its country, official website and allowed domains, recording verification evidence. A listed but unverified agency is not an active verified capture policy. Coverage gaps should remain visible; missing extracted requirements do not mean the jurisdiction has no requirements.
